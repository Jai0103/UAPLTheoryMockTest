UAPL Theory Mock Test (CAAS Preparation)

This repository contains a UAPL Theory Mock Test designed to help learners prepare for the Civil Aviation Authority of Singapore (CAAS) Unmanned Aircraft Pilot Licence (UAPL) theory examination.

The mock test provides learners with an opportunity to practice and strengthen their understanding of key UAPL theory topics. It is intended to support self-study, revision, and classroom training.

Features
Multiple-choice questions for UAPL theory practice
Covers key topics aligned with UAPL theory syllabus
Useful for self-learning and revision
Lightweight and browser-friendly (GitHub Pages compatible)
